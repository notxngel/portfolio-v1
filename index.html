Proceso

Cómo construyo un proyecto.

Control de versiones desde el primer día, vistas previas en cada etapa y un deploy que se puede repetir.

Defino qué tiene que hacer la aplicación, qué datos maneja y qué servicios necesita. De ahí sale el stack, la estructura del proyecto y un precio cerrado.

HTML semántico, CSS responsive y JavaScript para la interacción. Accesible con teclado y lector de pantalla, y probado en móvil desde el inicio.

Lógica en Node.js, consumo de APIs externas con peticiones HTTP asíncronas, autenticación cuando hace falta y variables de entorno fuera del código.

Publicación en Netlify, Vercel, GitHub Pages o un servidor Linux propio, con HTTPS y dominio. El repositorio y el código quedan a tu nombre.

Preguntas

Antes de empezar

¿Con qué tecnologías trabajas?

JavaScript en todo el stack: HTML, CSS y JS en el frontend, Node.js en el servidor y Linux para infraestructura. Ahora mismo estoy sumando React, Express y PostgreSQL.

¿Haces solo frontend o también backend?

Ambos. Puedo hacer solo la interfaz si ya tienes un backend, o construir la aplicación completa con su servidor e integraciones.

¿Dónde se aloja el proyecto?

Sitios estáticos en Netlify, Vercel o GitHub Pages, que son gratuitos para la mayoría de casos. Aplicaciones con servidor, donde mejor encaje según el proyecto.

¿Cuánto tarda?

Una landing suele tomar [__] semanas y una aplicación web [__] semanas. Te doy una fecha concreta cuando definimos los requisitos.

¿El código es mío?

Sí. Al terminar te entrego el repositorio completo y los accesos al hosting y al dominio.
